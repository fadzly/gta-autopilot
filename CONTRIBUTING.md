# Contributing

Start with [the tracker](TRACKER.md). Search existing issues by task ID, mission and checkpoint. Open a proposal to claim an item or describe a measurable improvement. Use a run report for an experiment and a bug report for a repeatable failure.

Fork the repository, make a focused branch and link the issue from your pull request. Include the behavior changed, how to reproduce it, checks performed, remaining limits and the affected tracker row. For documentation, verify paths, source links and status wording.

For a gameplay improvement, compare the same checkpoint before and after the change. Include failures, total attempts, interventions and the exact revision. Another contributor can repeat the run and link their report before promotion to validated. Publish only material you can share and redact personal information from evidence.
