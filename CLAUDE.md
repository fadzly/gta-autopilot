# Claude Code

@AGENTS.md

When contributing from Claude Code, start by selecting a tracker item and reading its acceptance criteria. For transport work, inspect the pinned server's tool list before mapping an operation. Record the Claude Code version and the actual image/tool result in the run report. Codex compatibility needs its own run.

For future supervised play sessions, request the named story objective and limits before enabling input. Treat ambiguous screens as a reason to release controls and pause. The proposed runtime and its interface are documented in docs/architecture.md.
